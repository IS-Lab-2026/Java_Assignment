question 1: Bicycle rental

  Project Description

  This Program is about a bicycle rental  that calculates the cost of renting a bicycle based on the starting 
  time and ending time entered by the user. It uses different hourly rates depending on the 
  rental time period.

  Objectives

 -to use user input with the scanner class to apply if , else if and else statements.
 -to calculate bicycle rental costs using different hourly rates.

 How the program works

 -the user enters the starting time.
 -the user enters the ending time
 -the program checks whether the entered times are valid.
 -this program calculates the rental cost according to the rate period.
 -the program displays the total cost in Rwandan francs (RWF) ,or an error message if the time is
  invalid or the rental crosses different rate periods.

  Rental Rates

 Time Period | Rate per Hour 

 00:00–07:00 :the rent will be 500 RWF 
 07:00–14:00 :the rent will be 1,000 RWF 
 14:00–19:00 :the rent will be 1,500 RWF 
 19:00–21:00 :the rent will be 1,000 RWF 
 21:00–24:00 :the rent will be 500 RWF 
 

  Example output

 enter starting time:8
 enter ending time :13
 total cost = 8000RWF



  Conclusion

 this program demonstrates basic java concepts, including variables, user inputs, the scanner class, conditional
 stamements, input validation and  arithmetic operations. it calculates the bicycle rental cost according to the 
 applicable hourly rate and displays the result in Rwandan francs. 

question 2: Mushroom identification

  Project Description

 this program is about mushroom identification by asking the user a series of questions. the user answers
 each question with yes or no, and the program uses if statements to determine the mushroom's name.

  Objectives

 - To identify mushrooms based on their characteristics.
 - To practice using if-else statements in Java.
 - To understand how user input works using the Scanner class.

   How the Program Works

 - this program asks the user to think of a mushroom.
 - The user answers questions about the mushroom using Yes or No.
 - This program follows different conditions based on the user's answers.
 - it uses if-else statements to follow the correct path. 
 - Lastly, the program displays the identified mushroom' names.

  Mushrooms Identified

 The program can identify six mushrooms:

 - Amanite tue-mouche
 - Girolle
 - Coprin chevelu
 - cepe de bordeaux
 - pied bleu
 - Agaric jaunissant


  Example Output

 Think of one mushroom.
 Answer using yes or no.
 Does it have a convex cap? yes
 Does it grow in a forest? yes
 Does it have a ring? no
 Your mushroom is: Pied bleu



  Conclusion

 This project demonstrates how Java can use user input and conditional statements to make decisions.
 it provides a simple way to identify mushrooms based on their characteristics. It helps beginners
 understand decision-making in programming.
