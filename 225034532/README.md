JAVA PROGRAMS


Project Description
--------------------
This project contains two Java programs 

1.java – Bicycle Rental Cost Calculator
This program calculates the total cost of renting a bicycle based on the
starting time and ending time entered by the user.

The program:
- Accepts the starting time (0–23) and ending time (1–24).
- Checks whether the entered times are valid.
- Calculates the rental duration in hours.
- Applies the hourly rate for each hour of rental:
  - Before 07:00 and from 21:00 onward: 500 RWF per hour.
  - From 07:00 to before 14:00: 1,000 RWF per hour.
  - From 14:00 to before 19:00: 1,500 RWF per hour.
  - From 19:00 to before 21:00: 1,000 RWF per hour.
- Displays the rental duration and total rental cost.
Example:Enter starting time (0-23): 8
Enter ending time (1-24): 10
Rental duration: 2 hours
Total rental cost: 2000 RWF

If the entered times are invalid, the program displays an error message.

2. java – Mushroom Identification System
This program identifies a mushroom by asking the user a sequence of
yes-or-no questions about its characteristics.

The questions concern whether the mushroom has gills, grows in a meadow,
has a ring, and has a convex cup. Based on the answers, the program displays
the identified mushroom.

The program accepts answers in uppercase or lowercase and ignores extra
spaces around the answers. If an invalid answer is entered for the first
question, the program displays "Invalid answer".


Example:
MUSHROOM IDENTIFICATION SYSTEM
Answer each question with yes or no.
Does your mushroom have gills? no
Identified mushroom: Cepe de bordeaux
