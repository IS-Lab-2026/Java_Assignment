This repository contains two Java programs that I created for my Lab 1 assignment. The programs helped me practice using variables, user input, conditions, loops, and decision-making statements in Java.

Problem 1: Bicycle Rental System

This program calculates the total amount a customer has to pay when renting a bicycle. The user enters the starting time and ending time in whole numbers. The program checks whether the entered times are valid before calculating the cost.

The rental price depends on the time of day. The rates are 500 RWF per hour from 00:00 to 07:00 and from 21:00 to 24:00, 1,000 RWF per hour from 07:00 to 14:00 and from 19:00 to 21:00, and 1,500 RWF per hour from 14:00 to 19:00.

After checking each hour of the rental period, the program adds the charges together and displays the total rental cost in RWF.

Problem 2: Mushroom Identification System

This program identifies a mushroom based on its characteristics. The user first thinks of one of the six mushroom types and answers questions about it.

The program asks about the presence of a ring, whether the mushroom grows in a forest, whether it has gills, and whether it has a convex cup. Depending on the answers, it determines the most likely mushroom from the six types provided in the assignment.

The program uses "if-else" statements to follow different paths based on the user's answers. It asks no more than three questions to identify the mushroom. The user must answer truthfully and can enter "yes" or "no", or use "y" or "n".
