# Bicycle Rent java Work 

At first we were asked to do java program that determine what Cost customers will have to pay for a Bicycle rental basing on 
two data as inputs starting Time and ending Time and Give Cost as Output.
 
The rate per hour depends on the range as follows :    
0 - 7    and 21- 24 : the rent will be 500 RWF per hour.   
7-14:   and 19h-21: rent will be 1000 RWF per hour .  
14-19 : the rent will be 1500 RWF per hour.

### Prerequisites
* **Java Development Kit (JDK)**: Version [8 / 11 / 17 or higher]

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd your-repo-name
   ```

### Running the Program
Since this program runs directly in the console environment, compile and run the entry class:

```bash
# Compile all Java files
javac *.java

# Run the main program
java Main
```
*(Note: If you are using an IDE like IntelliJ, Eclipse, or VS Code, you can simply open the project folder and click the green **Run** button on `Main.java`.)*
