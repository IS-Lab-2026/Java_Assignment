# My Java Programs

Two Java programs I made for my class.

## Bicyclerentings.java
Calculates the cost of renting a bicycle. The user enters the start hour and end hour, and the program prints the total.

## Mushroomfinder.java
A mushroom guessing game. The user answers 1 for yes or 2 for no, and the program tells them which mushroom it thinks they picked.

## How to run

```
javac Bicyclerentings.java
java Bicyclerentings
```

```
javac Mushroomfinder.java
java Mushroomfinder
```
