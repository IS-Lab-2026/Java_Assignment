# Lab 1

Two Java programs for Individual Lab 1, made with variables, decisions and loops.

## Files
- [Problem1.java](Problem1.java): Bicycle Rental. Works out the price of a rental from the start and end hour.
- [Problem2.java](Problem2.java): Mushroom Identification. Asks up to three yes or no questions and names the mushroom.

## How to run
1. Open the file in NetBeans.
2. Right-click inside the code and choose Run File.
3. Type the answers in the Output window and press Enter.
