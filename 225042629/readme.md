

# Java Programming Projects

## 1. Lucky Rental Cost Calculator

### Description
This Java program calculates the total rental cost based on the starting time and ending time entered by the user.

The rental cost depends on the number of hours rented and the price charged during different time periods.

### Rental Rates
- From 00:00 to before 07:00: 500 RWF per hour
- From 07:00 to before 14:00: 1000 RWF per hour
- From 14:00 to before 19:00: 1500 RWF per hour
- From 19:00 to before 21:00: 1000 RWF per hour
- From 21:00 to before 24:00: 500 RWF per hour

### How to Run
1. Open the project in a Java IDE, such as NetBeans.
2. Run the Lucky.java file.
3. Enter the starting time as an integer.
4. Enter the ending time as an integer.
5. The program displays the total rental cost in RWF.

### Example
Enter starting time: 8
Enter ending time: 11
Total rental cost = 3000 RWF

## 2. Mushroom Identification Program

### Description
This Java program identifies one of six mushrooms by asking the user a series of yes-or-no questions about the mushroom's characteristics.

The program uses conditional statements to determine the mushroom based on the user's answers.

### Mushrooms Identified
- Amanite tue-mouche
- Agaric Jaunissant
- Coprin chevelu
- Cepe de Bordeaux
- Pied bleu
- Girolle

### How to Run
1. Open the project in a Java IDE, such as NetBeans.
2. Run the MushroomJava.java file.
3. Think of one of the six mushrooms.
4. Answer the questions using yes or no.
5. The program displays the identified mushroom.

### Example
Think of one of the six mushrooms.
Answer only yes or no.

Does your mushroom have a ring? no
Does your mushroom have gills? no

Your mushroom is Cepe de Bordeaux.

## Requirements
- Java Development Kit (JDK)
- A Java IDE or a terminal that supports Java compilation and execution

## Concepts Used
- Variables and data types
- User input using Scanner
- Conditional statements (if, else if, and else)
- Loops (for loop)
- String handling
- Basic arithmetic operations
